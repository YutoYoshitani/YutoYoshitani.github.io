# 芳谷優斗のポートフォリオ

公開先：[yutoyoshitani.github.io](https://yutoyoshitani.github.io/)

公開リポジトリ：`YutoYoshitani/YutoYoshitani.github.io`

## 構成

- `index.html` — トップ、人物像と主要な3つの経験
- `stories/index.html` — 3つの軸から読む取り組みのストーリー
- `research/index.html` — 現在の研究構想、学会発表、実験と調査
- `about/index.html` — 5つのキーワード、日常の関心、本人制作物
- `assets/site.css` — 共通スタイル、レスポンシブ、印刷、動きを減らす設定
- `assets/site.js` — 詳細への直リンク、画像拡大、印刷時の詳細展開

フレームワークやビルド工程を持たないHTML・CSS・JavaScriptの静的サイトである
このディレクトリの中身を公開リポジトリのルートへ配置する
GitHub Pagesのユーザーサイトを維持し、公開URLに追加のサブディレクトリを付けない

## デザインと編集方針

- 鉄紺を基調に、紙色、錆色、苔色、黄土色を使い分ける
- 大見出し、罫線、非対称レイアウトで内容ごとの読み順をつくる
- データを企画、判断、周囲との実行につなげる人物像を示す
- 本人写真2点と本人制作のCanva画像3点のみ使用する
- 数値や研究成果を追加するときは事実ソースを確認する
- 実施済み、企画案、研究構想、未確認を区別する
- 企業研修の公開名は「食品宅配企業の商品企画研修」とする
- 本文はだ・である調とし、日本語の句点は用いない

## 動作

主要本文と詳細の開閉はJavaScriptなしでも利用できる
画像拡大はネイティブdialogによる追加機能であり、非対応環境では元の画像リンクとして動作する
画像データは元のまま保持し、キャプションと拡大導線を付けている

CSS・JavaScriptを変更する際は4ページのクエリ版番号も揃える
現在の版番号は `20260919-4`
