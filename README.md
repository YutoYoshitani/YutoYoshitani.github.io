# 就職活動用ポートフォリオ

4ページの静的ポートフォリオサイト

- `index.html`　トップ
- `stories/index.html`　取り組みのストーリー
- `research/index.html`　研究
- `about/index.html`　人物

## 公開前に設定する内容

- 公開用メールアドレス
- GitHubユーザー名
- 新入生フェアの確認済み情報
- 角煮レシピの材料と分量
- 訪問済みのおすすめ旅行スポット

## GitHub Pagesへ公開する場合

公開用の別リポジトリを作成し、このフォルダの中身だけをルートへ配置する

リポジトリ名は `GitHubユーザー名.github.io` とする

GitHub Pagesの公開設定でGitHub Actionsまたは配信元を設定する
