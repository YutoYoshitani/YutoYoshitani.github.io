## 公開後に更新する内容

- 公開用メールアドレスを設定したらフッターの案内を差し替える
- 新入生フェアの確認済み情報を追記する
- 角煮レシピの材料と分量を追記する
- 訪問済みのおすすめ旅行スポットを追記する

## GitHub Pagesへ公開する場合

公開用の別リポジトリを作成し、このフォルダの中身だけをルートへ配置する

リポジトリ名は `GitHubユーザー名.github.io` とする

GitHub Pagesの公開設定でGitHub Actionsまたは配信元を設定する
